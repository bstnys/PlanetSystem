# PlanetSystem

p5.js로 만든 행성계 시뮬레이션입니다. Flocking 예제의 구조(관리 클래스 + applyForce → update → render)를 참고했습니다.

- 태양 · 행성 5개(메르, 테라, 마르, 유피, 네오) · 위성들이 공전하고 자전합니다. 공전 속도는 케플러 법칙을 따릅니다.
- **클릭**: 소행성 만들기 / **드래그 후 놓기**: 소행성 던지기 (예상 궤도 미리보기)
- 소행성은 모든 천체의 중력을 받아 궤도가 휘고, 부딪히면 파편이 튑니다.
- **스페이스바**: 테라에서 랜덤한 행성을 향해 로켓을 순행 발사합니다. 로켓은 소행성에 닿으면 폭발하고, 행성에 닿으면 착륙하며 사라집니다.
- **C**: 소행성 모두 지우기
